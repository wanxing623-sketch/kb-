# 图片体积压缩（单文件本地版）

保持图片原始像素宽高与视觉画质，把一个或多个图片的体积精准压到目标 KB 以内，全部在浏览器本地完成。

## 使用方法

用任意现代浏览器（Chrome / Edge / Safari / Firefox）双击打开 [`index.html`](./index.html) 即可离线使用。无需安装、无需联网，图片不会被上传到任何服务器。

1. 输入目标上限（KB 或 MB），或直接点 `50K / 100K / 200K / 500K / 1M` 快捷值；
2. 点击选择、拖入或直接 `Ctrl+V` 粘贴一张或多张图片；
3. 每张图片行右侧会实时显示压缩后的精确体积（如 `97.21 KB`）与是否达标；
4. 点「下载」保存单张，或点「打包下载 ZIP」保存全部。

## 功能说明

- **批量处理**：支持多选、拖拽、剪贴板粘贴，可随时继续追加图片；多张时自动排队并行压缩。
- **精准目标控制**：以目标值为硬上限（内置小数级安全余量），压缩后在列表中显示每张的实际 KB 数。
- **不缩像素、保真优先**，处理顺序为：
  1. 原图已小于目标 → **零损耗原样保留**，不重新编码；
  2. 尝试**无损剥离** EXIF / XMP / 缩略图 / 彩色 Profile / Photoshop 注释等冗余元数据（像素数据一字节不改，仅重排容器）；
  3. 必须重编码时，**严格锁定原始宽 × 高**，用 MozJPEG 进行渐进式 + Trellis 量化寻优，在目标体积内取可用的最高质量；PNG 则优先无损重排，其次感知调色板量化；
  4. 智能格式模式下，只有原格式确实无法达标时才改格式（如 PNG 照片 → JPG），并在列表中明确标注 `PNG → JPG`。
- **极小目标的处理**：当目标小于该分辨率下的理论下限时，会明确提示「原尺寸下限」，并给出两个**需手动确认**的选项：转 WebP 再压小、允许等比缩小像素；绝不静默改变尺寸。
- **画质对比**：点缩略图或「对比」可左右拖动分割线对比原图与压缩图，支持 `1:1 原始像素` 检查细节。
- **透明背景安全**：转为 JPG 时自动合成白底，不会出现黑块。
- **下载**：单张下载文件名形如 `原文件名_97KB.jpg`；多张可逐张下载或打包为 `.zip`（文件名保持原名）。

## 兼容性

- 现代浏览器（Chrome / Edge / Firefox / Safari 14+）。
- 压缩内核运行在 Web Worker 中，页面不卡顿；若浏览器限制 Worker（如某些本地文件策略），自动回退到主线程处理。
- 解码依赖浏览器自身能力，支持 JPG / PNG / WebP / BMP / GIF（首帧）等；HEIC / RAW 等浏览器无法解码的格式会给出提示。

## 致谢开源项目

`index.html` 为单文件离线版，内置封装并打包了以下开源项目（均以 WebAssembly / JS 在本机运行）：

- [mozilla/mozjpeg](https://github.com/mozilla/mozjpeg) 与 [jSquash (`@jsquash/jpeg`)](https://github.com/jamsinclair/jSquash) — 渐进式、Trellis 量化高保真 JPEG 编码器
- [photopea/UPNG.js](https://github.com/photopea/UPNG.js) — PNG 无损重排与感知色彩量化压缩
- [101arrowz/fflate](https://github.com/101arrowz/fflate) — Deflate / Zlib 压缩与本地 ZIP 归档

感谢以上项目及其作者的开源工作。
